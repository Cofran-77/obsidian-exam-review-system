# 错题本数据字典

## 知识图谱层级

```text
学科 → 板块 → 核心专题 → 知识点 → 错题
```

## 图谱连线规则

图谱只保留能够回答“这个节点为什么与另一个节点有关”的链接：

- **板块 → 核心专题**：说明课程目录中的专题归属。
- **学科大纲 → 板块**：说明该学科的课程边界；学科大纲不直接连接专题或知识点。
- **板块 → 知识点索引**：通过 Dataview 展示该板块覆盖的知识范围，不制造额外图谱边。
- **核心专题 → 知识点**：说明专题覆盖哪些可考知识点。
- **知识点 → 知识点**：只用于概念对比、前后推导或跨专题迁移。
- **知识点 → 错题**：说明该错题是这个知识点的实战证据。

以下内容不参与知识图谱连线：复习看板、导出汇总、返回导航、板块页的 Dataview 知识点索引、错题的专题展示字段。它们仍可作为页面阅读和查询使用。

图谱默认展示完整知识体系：全局总纲 → 五个学科大纲 → 各学科板块 → 核心专题 → 知识点。错题节点默认隐藏在全局图谱中，但仍保留在板块、知识点和错题卡片的页面预览中；需要检查错题证据时，可在图谱搜索中移除 `-path:"02-错题"`。

| 节点 | 文件位置 | 稳定 ID | 作用 |
|---|---|---|---|
| 学科 | `01-*` 至 `05-*` | `subject` | 课程边界 |
| 板块 | `01-板块` | 文件名/模块名 | 课程目录 |
| 核心专题 | `04-核心专题枢纽` | `TH-XX-001` | 组织多个知识点 |
| 知识点 | `03-知识点` | `KP-XX-001` | 解释一个可考概念 |
| 错题 | `02-错题` | `XX-001` | 记录一次具体错误 |

## 错题字段

| 字段 | 说明 |
|---|---|
| `id` | 唯一卡片 ID，不随标题变化 |
| `subject` / `module` | 学科和板块 |
| `target_kp_id` / `thematic_hub_id` | 主要知识点和专题 ID |
| `source_file` / `source_page` | 原题来源和页码 |
| `error_category` / `error_subtype` | 可统计的错误大类和子类 |
| `difficulty` | 1 至 5，主观难度 |
| `status` | `待复习`、`待攻关`、`复习中`、`已掌握`、`已归档` |
| `review_result` | `未复习`、`again`、`hard`、`good` |
| `review_count` | 已完成复习次数 |
| `last_review` / `next_review` | 最近复习日和下一次到期日 |

## 轻量复习规则

- `again`：下一次安排在明天
- `hard`：下一次安排在三天后
- `good`：下一次安排在七天后
- 今日队列只显示 `next_review <= date(today)` 且未标记为 `已掌握` 的卡片
